# Privacy Policy — 5AbsurdFacts Publisher

Last updated: 2026-07-13

5AbsurdFacts Publisher ("the Client") is a private, non-commercial script developed
and used by a single individual (the developer) to upload the developer's own videos
to the developer's own YouTube channel (https://www.youtube.com/@5AbsurdFacts).

## Use of YouTube API Services

The Client uses YouTube API Services. By using it, the user agrees to be bound by the
YouTube Terms of Service (https://www.youtube.com/t/terms). The Google Privacy Policy
applies: http://www.google.com/policies/privacy

## Data the Client accesses, collects and stores

- The Client is used only by its developer. It has no external users, no website,
  and no user accounts.
- The Client only uses the `youtube.upload` OAuth scope, exclusively to upload videos
  to the developer's own authenticated channel.
- It does not access, collect, store, process, or share any personal data of third
  parties, and it does not retrieve, store, or display any YouTube API data.
- The developer's own OAuth 2.0 credentials (access/refresh token) are stored locally
  on the developer's machine and as encrypted CI repository secrets, and are used
  solely to authorize uploads. They are never shared.

## Data sharing

No data is shared with any third party.

## Revoking access

API access can be revoked at any time from the Google account security page:
https://myaccount.google.com/permissions. Revocation invalidates all stored tokens.
